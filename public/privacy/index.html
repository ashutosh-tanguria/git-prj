Shelf privacy

Shelf has no telemetry, analytics or crash reporting. Connected providers receive requests when you sign in and use their files.

The OAuth Worker relays GitHub App authorization codes and credentials for token exchange, refresh and revocation. It stores no credentials or files. Repository previews run on a separate origin and receive selected preview files and paths.

Access tokens are held in memory. If you choose to remember GitHub sign-in, the refresh credential stays encrypted on this device. Listings, settings, collections and indexes use local browser storage. Cached and pending file bytes are stored locally. In Shelf, open Settings and Privacy for retention details or Settings and Storage to wipe local data.
