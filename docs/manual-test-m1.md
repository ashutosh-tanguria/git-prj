# M1 real-account manual test

This checklist is for the owner. Real-account verification has not been performed by the coding agent. Record browser/version, operating system, viewport, date, repository, and pass/fail evidence without exposing credentials.

1. Create a disposable GitHub repository initialized with a README. Add two folders, several text/Markdown files, an image, and a searchable PDF with at least 20 pages, an outline and several repeated search terms. Include long filenames and a filename containing spaces or non-Latin text. Use test documents with no sensitive information.
2. Create a short-lived fine-grained PAT at GitHub Settings > Developer settings > Personal access tokens > Fine-grained tokens. Restrict it to the disposable repository. Choose Contents read/write and Metadata read as specified in SETUP.md. Obtain organization approval if required. Never paste the PAT into an address, chat, source file, screenshot or environment variable.
3. Run npm ci, then npm run dev. Open the product root. Enter the PAT in the GitHub token field and validate. Confirm the repository appears, the token input clears, and the URL contains no credential. Disconnect and confirm the connection form returns; reconnect for the remaining checks.
4. Use Locations with arrows, Home/End, type-ahead and Enter. Expand a repository/folder with Right, collapse with Left, and expand sibling folders with *. Verify the file listing matches GitHub and submodules/symlinks cannot be opened as regular files. Browse into a folder and use Backspace or Alt+Up to return to its parent.
5. Select a row by clicking its empty area or filename. Ctrl-click (Cmd-click on macOS) to toggle another row; Shift-click to select a range. Test Shift+Up/Down, Ctrl/Cmd+A, and Ctrl/Cmd+Space. Drag a rectangle beginning in an empty cell/space across rows and check the selected range. Click an unchecked checkbox and test Shift-clicking checkboxes.
6. Move focus into the file grid using Tab. Confirm only one file row is in the Tab order. Use Up/Down, Home/End and type-ahead to reach files beyond the current scroll window. Enter opens the focused file; Space opens Quick Look. Escape closes Quick Look and returns focus to the row. Left/Right in Quick Look moves through file siblings. Enter while the preview region is focused opens the full viewer.
7. Click Name/Size/Changed/Last change headers to sort; reverse the direction. Drag the separators or focus one and press Left/Right to resize. Open Columns, hide/show columns, and invoke the chooser through the header context menu. Reload and reconnect; confirm the location retains its sort and widths. Scroll a long list and confirm headers remain visible and rows do not overlap. Exact timestamps and full commit messages are available on hover and in Details; unavailable metadata must say Unknown.
8. Press Ctrl/Cmd+L, edit the provider reference, and press Enter. Escape restores the current address. Use Alt+Left/Right to traverse browser history. Confirm names with spaces and branch names containing slashes remain valid through encoded links. On browsers that reserve Ctrl/Cmd+L, click the Address field or Tab to it as a fallback and record that browser behavior.
9. Toggle Locations with Ctrl/Cmd+B and Inspector with Ctrl/Cmd+Alt+B. Resize each pane using its named width slider, reload/reconnect, and verify widths persist. Confirm focus stays visible and closing a drawer/sheet restores focus to its trigger.
10. Select one file and open Inspector. Preview must show the selected file; Details must show provider/location, exact byte count, type, ref, content hash, timestamp/message when known, visibility and cache status. Copy path/hash and verify the copied values. Select multiple files and confirm their count/known byte total and the single-preview guidance. History is deliberately absent until M3.
11. Open the PDF. At narrow or short heights, expand PDF controls first; fit actions collapse them again. Switch Single page/Continuous, Fit width/Fit page, and zoom to 25 and 400 percent. Check text remains selectable. Open thumbnails and choose a page; open the outline and choose a destination. A PDF without outline must state that clearly. Reading mode changes page appearance without changing the file.
12. Search for a phrase and test next/previous matches. Confirm matches are highlighted, including text split across font runs. Search for text absent from the document and check the zero-result state. Use j/k, PgDn/PgUp, +/-, /, and g followed by a page number and Enter with focus in the PDF reader. Shortcuts must not interfere with typing in fields.
13. Navigate to page 12 and set zoom to 125 percent. Copy the viewer link, reload, and reconnect. Confirm the same file, page and zoom return. Close/reopen and confirm the same. The PAT must not be remembered. Browser data clearing or private mode may discard non-secret reading preferences.
14. In Continuous mode, scroll far away from earlier pages. Observe that nearby pages render while far canvases/text layers are released. Revisit an earlier page and confirm it renders again. Check an encrypted/password-protected or damaged PDF fails with an actionable read error rather than executing document actions.
15. Test widths at 1440, 1024, 768 and 360 CSS pixels: all panes at wide width; Inspector initially collapsed at 1024; Locations rail and Inspector sheet at 768; Locations drawer, Inspector bottom sheet, two-line file rows and selection actions at 360. Confirm drawer/sheet focus is trapped and Escape closes it. At 360 on a touch device, long-press a row to enter selection mode, scroll normally without accidental selection, and verify read actions need no drag and drop.
16. Repeat Explorer with a selection, Inspector and PDF checks in light/dark themes, 200 percent zoom, forced colors and reduced motion. On the development Styleguide route, use the theme/density controls; a system theme also applies when no explicit override is set. Capture screenshots with credentials hidden. Verify skip links, visible focus, polite selection announcements and error announcements with a screen reader (NVDA or VoiceOver).
17. Confirm the GitHub 100 MB/1 GB sentence stays visible, and no remote write occurs during these tests. M1 has no staging/push behavior. Revoke the disposable PAT in GitHub when finished. Record failures and reproduction steps without tokens or private document contents.
