# M6a manual acceptance

Use disposable repositories and the deployment instructions in [Deploy Shelf](deploy.md). Use Chrome for installation and extension checks. The icons are placeholders.

1. Open Shelf without OAuth variables and use a selected-repository PAT. Verify Connect remains present with both OAuth variables configured.
2. Install the GitHub App on two selected repositories. Start sign-in from Shelf and verify the callback path ends in `/auth/github/`, the final URL has no OAuth query parameters or token, and only installed accessible repositories are listed. Confirm that Install on more repositories opens GitHub. Create a disposable repository through the GitHub fallback, add it to the installation and refresh the list.
3. With Remember off, reload and check that Shelf asks you to reconnect. Enable Remember with a passphrase, examine the encrypted IndexedDB record, reload and try an incorrect passphrase. Verify the delay before another attempt, then unlock with the correct passphrase. Set a short idle timer and confirm the app locks while pending changes remain. Sign out and verify GitHub removes the grant. With the browser offline, confirm a revocation failure gives the GitHub settings recovery message.
4. Browse a disposable private repository and run a website preview. Verify the two response header sets and no token in any sandbox request or message. Confirm the browser shows the origin A banner and rejects a third origin embedding the sandbox.
5. Install Shelf, browse a folder and open a file, then reload with the network off. The cached library and visited file should open. Disable the network during a staging or push attempt and verify Pending survives.
6. With a push or transfer active in one app tab, deploy a second build and accept the update prompt in another tab. Confirm Shelf waits for the active operation. Accept again after completion. The app should reload and retain pending changes. Separately verify accessibility and PWA scores using `npx --yes --package @lhci/cli@0.13.0 lhci autorun` after building.
7. Load the unpacked extension. Verify Open in Shelf on a repository, a nested file, a branch containing a slash and a non-repository page. Check that the extension grants only GitHub site access. Inspect the ZIP before distributing it.
8. Open Settings → Privacy in English and review the same specimen in Hindi. Copy diagnostics after a provider error. Confirm it contains only version, browser family and major version, feature availability and known error codes. Confirm the storage rows, no telemetry statement and host list are present. Wipe local data and verify cached bytes, pending records, settings and any remembered sign-in are gone.
